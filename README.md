
# Blue Fig AI Concierge

A premium, bilingual (Arabic/English) Voice AI Concierge for Blue Fig Restaurant in Amman.

## Features
- **Voice Interaction**: Real-time Levantine Arabic and English conversation via Gemini Live API.
- **Digital Menu**: Interactive, searchable, and filtered food/drink menu.
- **Service Feed**: Staff dashboard for receiving orders, assistance calls, and guest reviews.
- **Order Management**: AI-driven ordering system with automated kitchen notifications.

## Tech Stack
- React 19
- Google Gemini API (Live)
- Tailwind CSS
- ntfy.sh (Staff Notifications)

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`
3. Set your `API_KEY` in the environment.
4. Run development server: `npm run dev`
